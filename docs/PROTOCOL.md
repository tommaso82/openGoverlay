# Target interface

## Hardware identification

- Target: LCDSysInfo GOverlay 3.5-inch USB display.
- Nominal resolution: 480 × 320.
- USB vendor/product ID: 20A0:41ED (publicly documented identification; verify against the actual device).

The project aims to communicate with the display using standard USB host APIs and an independently developed implementation.

## Specification status

A public functional specification is not yet available. Only interface details necessary for interoperability, with reviewed provenance and appropriate validation, will be published. No proprietary implementation material or protection-related procedures will be included.

See [INTEROPERABILITY.md](INTEROPERABILITY.md) and [SAFETY.md](SAFETY.md).

# Preliminary research status — 2026-11-24

The project is evaluating the feasibility of independent software for the LCDSysInfo GOverlay 3.5-inch USB display. Research is preliminary. No hardware validation or working implementation is claimed.

Public documentation will be limited to independently written, reviewed functional information necessary for interoperability. Detailed working notes are not part of the public specification.

The initial scope excludes persistent configuration changes, firmware updates, and device-restriction management.

See [INTEROPERABILITY.md](INTEROPERABILITY.md) and [TESTS.md](TESTS.md).

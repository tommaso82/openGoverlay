## Trasporto USB

LCDsysinfo2::.ctor (2710): VID 8352 / PID 16877 (20A0:41ED). Control transfer vendor-specific, recipient device: OUT 0x40, IN 0xC0. Setup little-endian, molti payload grafici big-endian. Distinguere request type da opcode.

LibUsbDriverIO::ControlTransfer (471 nella DLL, IL 0x02B8–0x03C1) copia request/value/index nei campi IOCTL e usa la lunghezza separata per il buffer. UsbSetupPacket.Length spesso vale zero; nella futura API usare la lunghezza effettiva.

## Catalogo e primi candidati

Il catalogo dei request osservati e le combinazioni note, con gli offset IL di riferimento, sono mantenuti in [PROTOCOL.md](PROTOCOL.md). La tabella copre i costruttori di setup della classe e i due opcode calcolati di Draw_Lines, non tutti gli opcode del firmware. I metodi dinamici potrebbero accettarne altri.

Firmware: secondo byte della risposta. Seriale: conservare gli 8 byte grezzi; la concatenazione decimale originale non è univoca in generale. Pixel: big-endian RGB565. Limiti X 0–479, Y 0–319. Luminosità normale 0–255. ClearLines usa sei bit 1,2,4,8,16,32; 63 seleziona tutti; geometria delle regioni da verificare.

## Framebuffer: errore host confermato staticamente

readScreenFromDevice (2739) esegue 1228 letture da 250 byte (indici 0–1227), copia 250 byte per iterazione senza verificare il numero trasferito. Totale 307000 byte invece di 307200 per 480×320 RGB565: mancano 200 byte (100 pixel). Buffer inizializzato a zero. Richieste OUT della famiglia flash prima e dopo (IL 0x0097 e 0x031A); esclusa dalla whitelist iniziale. Non si sa se il firmware accetti un ultimo blocco di 200 byte.

## Grafica e testo

- Draw_Pixels (2754): 6 byte per elemento, ordine Y,X,colore, a 16 bit big-endian. Value = 6×numero di elementi, Index 4, request BF. Allocazione originale con un byte extra; distinguere lunghezza effettiva.
- Draw_Rectangle (2731): payload Y1,X1,Y2,X2,colore; variante con raggio. Lunghezze effettive e varianti multiple da tabulare individualmente.
- Draw_Text_Font (2746): regular ID 0, regular_small ID 1, font personalizzati. ASCIIEncoding, non assumere UTF-8. Trasparenza 12345. Font integrati 0x19, personalizzati 0xBE. Layout differenti per offset e dimensioni.
- Draw_Lines (2755): connesse 0x22, Value numero punti meno uno; indipendenti 0x86. Non assumere ordine X/Y uniforme.

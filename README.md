# OpenGOverlay

An independent interoperability project for the LCDSysInfo GOverlay 3.5-inch USB display.

**Status: preliminary research. No driver, release or hardware validation yet.**

## Goals

- Lightweight standalone software for legitimately owned displays.
- Windows and Linux compatibility.
- Local operation and efficient display updates.
- Independently developed implementation and reviewed documentation.
